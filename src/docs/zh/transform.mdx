## 示例

### 硬件加速

如果你的过渡在 GPU 渲染时表现优于 CPU，可以加上 `transform-gpu` 工具类强制启用硬件加速：

```html
<!-- [!code classes:transform-gpu] -->
<div class="scale-150 transform-gpu">
  <!-- ... -->
</div>
```

如果在某些情况下需要取消硬件加速，可以使用 `transform-cpu` 工具类把渲染交回给 CPU。

### 移除变换

使用 `transform-none` 工具类，一次性移除元素上所有的 transform：

```html
<!-- [!code classes:transform-none] -->
<div class="skew-y-3 md:transform-none">
  <!-- ... -->
</div>
```
