默认情况下 `dark` 变体使用 `prefers-color-scheme` CSS 媒体特性；你也可以通过覆盖 `dark` 变体来构建[手动切换深色模式](#toggling-dark-mode-manually)的站点。

## 手动切换深色模式

如果你希望深色主题由 CSS 选择器（而非 `prefers-color-scheme` 媒体查询）驱动，覆盖 `dark` 变体使其使用你的自定义选择器：

```css
/* [!code filename:app.css] */
@import "tailwindcss";

/* [!code highlight:2] */
@custom-variant dark (&:where(.dark, .dark *));
```

这样 `dark:*` 工具类不再依据 `prefers-color-scheme` 应用，而是会在 HTML 树中较高位置存在 `dark` 类时生效：

```html
<!-- [!code filename:HTML] -->
<!-- [!code word:dark\:bg-black] -->
<!-- [!code word:dark] -->
<html class="dark">
  <body>
    <div class="bg-white dark:bg-black">
      <!-- ... -->
    </div>
  </body>
</html>
```

如何把 `dark` 类加到 `html` 元素上由你决定，常见做法是用一小段 JavaScript 更新 `class` 属性，并把偏好同步到 `localStorage` 之类的位置。

### 使用 data 属性

如果想用 data 属性而不是类来激活深色模式，把 `dark` 变体覆盖为属性选择器即可：

```css
/* [!code filename:app.css] */
@import "tailwindcss";

/* [!code highlight:2] */
@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));
```

之后只要祖先节点的 `data-theme` 属性被设为 `dark`，深色模式工具类就会生效：

```html
<!-- [!code filename:HTML] -->
<!-- [!code word:dark\:bg-black] -->
<!-- [!code word:data-theme="dark"] -->
<html data-theme="dark">
  <body>
    <div class="bg-white dark:bg-black">
      <!-- ... -->
    </div>
  </body>
</html>
```

### 支持系统主题

要构建支持浅色、深色与跟随系统三态切换的主题开关，可以使用自定义的深色模式选择器，并借助 [`window.matchMedia()` API](https://developer.mozilla.org/en-US/docs/Web/API/Window/matchMedia) 检测系统主题，按需更新 `html` 元素。

下面是一个支持浅色、深色与跟随操作系统偏好的简单示例：

```js
// [!code filename:spaghetti.js]
// 页面加载或切换主题时，最好将这段脚本内联到 `head` 中，避免 FOUC
document.documentElement.classList.toggle(
  "dark",
  localStorage.theme === "dark" ||
    (!("theme" in localStorage) && window.matchMedia("(prefers-color-scheme: dark)").matches),
);

// 用户显式选择浅色模式
localStorage.theme = "light";

// 用户显式选择深色模式
localStorage.theme = "dark";

// 用户显式选择跟随系统偏好
localStorage.removeItem("theme");
```

同样地，你可以按自己的方式管理这件事，甚至可以把偏好存储在服务端数据库里、在服务端渲染时输出对应的类——完全由你决定。
