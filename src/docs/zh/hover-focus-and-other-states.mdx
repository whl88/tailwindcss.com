Tailwind 中的每个工具类都可以在类名前加上**变体**前缀，从而按条件应用样式。

例如，要在 hover 时应用 `bg-sky-700`，使用 `hover:bg-sky-700`：

        Save changes
      </button>
    </div>
  }
</Example>

```html
<!-- [!code classes:hover:bg-sky-700] -->
<button class="bg-sky-500 hover:bg-sky-700 ...">Save changes</button>
```

<details className="mb-10 rounded-xl border border-gray-200 px-6 py-3 prose open:pb-5 dark:prose-dark dark:border-gray-800">
<summary className="font-medium cursor-default select-none text-gray-900 dark:text-gray-200">这和传统 CSS 写法有什么区别？</summary>

用传统方式写 CSS 时，同一个类名在不同状态下会对应不同样式：

<TipBad>{<>传统写法中，同一个类名在 hover 等状态下会应用不同样式</>}</TipBad>

```css
.btn-primary {
  background-color: #0ea5e9;
}

.btn-primary:hover {
  background-color: #0369a1;
}
```

在 Tailwind 中，不是往已有类上「追加」hover 样式，而是为元素再添加一个**只在 hover 时生效**的类：

<TipGood>{<>在 Tailwind 中，默认状态与 hover 等状态分别用不同的类表示</>}</TipGood>

```css
.bg-sky-500 {
  background-color: #0ea5e9;
}

.hover\:bg-sky-700:hover {
  background-color: #0369a1;
}
```

注意 `hover:bg-sky-700` **只**描述 `:hover` 状态的样式：默认下不会生效，一旦悬停，背景色会变为 `sky-700`。

这就是所谓工具类可以**按条件**应用——通过变体，你可以在不离开 HTML 的前提下，精确控制界面在不同状态下的表现。

</details>

Tailwind 内置了几乎所有常见场景所需的变体，包括：

- [伪类](#pseudo-classes)，如 `:hover`、`:focus`、`:first-child`、`:required`
- [伪元素](#pseudo-elements)，如 `::before`、`::after`、`::placeholder`、`::selection`
- [媒体与特性查询](#media-and-feature-queries)，如响应式断点、深色模式、`prefers-reduced-motion`
- [属性选择器](#attribute-selectors)，如 `[dir="rtl"]`、`[open]`
- [子代选择器](#child-selectors)，如 `& > *` 与 `& *`

多个变体还可以**堆叠**，以应对更细的场景，例如在中等断点、深色模式且 hover 时修改背景色：

```html
<!-- [!code classes:dark:md:hover:bg-fuchsia-600] -->
<button class="dark:md:hover:bg-fuchsia-600 ...">Save changes</button>
```

本指南会介绍框架中每个变体的用法、如何与自定义类配合，以及如何编写自己的变体。

使用 `nth-*` 和 `nth-last-*` 变体，根据子元素在列表中的位置进行样式设置：

```html
<!-- [!code classes:nth-3:underline,nth-last-5:underline,nth-of-type-4:underline,nth-last-of-type-6:underline] -->
<div class="nth-3:underline">
  <!-- ... -->
</div>

  <!-- ... -->
</div>
<div class="nth-of-type-4:underline">
  <!-- ... -->
</div>
<div class="nth-last-of-type-6:underline">
  <!-- ... -->
</div>
```

默认可向其中传入任意数字，也可使用任意值处理更复杂的表达式，例如 `nth-[2n+1_of_li]`。

#### 任意 group 变体

可将自定义选择器作为[任意值](/docs/adding-custom-styles#using-arbitrary-values)写在方括号中，临时定义 `group-*` 变体：

  filenames={["HTML", "Generated CSS"]}

  <CodeBlock

#### 隐式 group（in-*）

`in-*` 变体的用法与 `group` 类似，但**不必**在父元素上写 `class="group"`：

{/* prettier-ignore */}
```html
<!-- [!code classes:in-focus:opacity-100] -->
<!-- [!code --:3] -->
<div tabindex="0" class="group">
  <div class="opacity-50 group-focus:opacity-100">
<!-- [!code ++:3] -->
<div tabindex="0">
  <div class="opacity-50 in-focus:opacity-100">
    <!-- ... -->
  </div>
</div>
```

`in-*` 会响应**任意祖先**的状态变化；若需要更精确的控制，请改用 `group`。

## 媒体与特性查询

### 响应式断点

要在特定断点下设置样式，请使用 `md`、`lg` 等响应式变体。

例如，小屏为 3 列网格，中等屏为 4 列，大屏为 6 列：

```html
<!-- [!code classes:md:grid-cols-4,lg:grid-cols-6] -->
<div class="grid grid-cols-3 md:grid-cols-4 lg:grid-cols-6">
  <!-- ... -->
</div>
```

若要根据**父容器**宽度而不是视口宽度设置样式，请使用 `@md`、`@lg` 等容器查询变体：

```html
<!-- [!code classes:@container,@md:flex-row] -->
<div class="@container">
  <div class="flex flex-col @md:flex-row">
    <!-- ... -->
  </div>
</div>
```

详见[响应式设计](/docs/responsive-design)文档，了解这些能力如何工作。

### @supports

使用 `supports-[...]` 变体，根据用户浏览器是否支持某个特性来设置样式：

```html
<!-- [!code classes:supports-[display:grid]:grid] -->
<div class="flex supports-[display:grid]:grid ...">
  <!-- ... -->
</div>
```

在底层，`supports-[...]` 变体会生成 [`@supports` 规则](https://developer.mozilla.org/en-US/docs/Web/CSS/@supports)，方括号内可写你在 `@supports (...)` 中使用的任意内容，例如属性/值对，或使用 `and`、`or` 组合的表达式。

为简洁起见，若只需检测**是否支持某属性**（不关心具体取值），可直接写属性名：

```html
<!-- [!code classes:supports-backdrop-filter:bg-black/25,supports-backdrop-filter:backdrop-blur] -->
<div class="bg-black/75 supports-backdrop-filter:bg-black/25 supports-backdrop-filter:backdrop-blur ...">
  <!-- ... -->
</div>
```

使用 `not-supports-[...]` 变体，根据用户浏览器是否**不**支持某个特性来设置样式：

```html
<!-- [!code classes:not-supports-[display:grid]:flex] -->
<div class="not-supports-[display:grid]:flex">
  <!-- ... -->
</div>
```

可以为项目中常用的 `@supports` 规则在 `supports-*` 命名空间下配置快捷变体：

```css
@custom-variant supports-grid {
  @supports (display: grid) {
    @slot;
  }
}
```

然后在项目中使用这些自定义 `supports-*` 变体：

```html
<!-- [!code classes:supports-grid:grid] -->
<div class="supports-grid:grid">
  <!-- ... -->
</div>
```

### data 属性

使用 `data-*` 变体，根据 [data 属性](https://developer.mozilla.org/en-US/docs/Learn/HTML/Howto/Use_data_attributes)按需应用样式。

若要检测某个 data 属性**是否存在**（不关心具体取值），直接写属性名即可：

```html
<!-- 会应用 -->
<!-- [!code classes:data-active:border-purple-500] -->
<div data-active class="border border-gray-300 data-active:border-purple-500">
  <!-- ... -->
</div>

<!-- 不会应用 -->
<div class="border border-gray-300 data-active:border-purple-500">
  <!-- ... -->
</div>
```

若需要匹配**具体取值**，可使用任意值语法：

```html
<!-- 会应用 -->
<!-- [!code classes:data-[size=large]:p-8] -->
<div data-size="large" class="data-[size=large]:p-8">
  <!-- ... -->
</div>

<!-- 不会应用 -->
<div data-size="medium" class="data-[size=large]:p-8">
  <!-- ... -->
</div>
```

此外，可为项目中常用的 data 属性在 `data-*` 命名空间下配置快捷变体：

```css
<!-- [!code filename:app.css] -->
@import "tailwindcss";

@custom-variant data-checked (&[data-ui~="checked"]);
```

然后在项目中使用这些自定义 `data-*` 变体：

```html
<!-- [!code classes:data-checked:underline] -->
<div data-ui="checked active" class="data-checked:underline">
  <!-- ... -->
</div>
```

## 自定义变体

### 使用任意变体

与[任意值](/docs/adding-custom-styles#using-arbitrary-values)让你在工具类中使用自定义 CSS 值类似，**任意变体**让你可以直接在 HTML 里书写自定义选择器变体。

任意变体是用方括号包起来的、表示选择器的格式字符串。例如下面这个任意变体在元素带有 `is-dragging` 类时将光标改为 `grabbing`：

<CodeExampleGroup
  filenames={["HTML", "Generated CSS"]}
>
  <CodeBlock
    example={svelte`
      <!-- [!code classes:[&.is-dragging]:cursor-grabbing] -->
      <ul role="list">
        {#each items as item}
          <li class="[&.is-dragging]:cursor-grabbing">{item}</li>
        {/each}
      </ul>
    `}

/>

  <CodeBlock
    example={css`
      .\[\&\.is-dragging\]\:cursor-grabbing {
        &.is-dragging {
          cursor: grabbing;
        }
      }
    `}
  />
</CodeExampleGroup>

任意变体可与内置变体或其它任意变体叠写，规则与 Tailwind 中其它变体一致：

<CodeExampleGroup
  filenames={["HTML", "Generated CSS"]}
>
  <CodeBlock
    example={svelte`
      <!-- [!code classes:[&.is-dragging]:active:cursor-grabbing] -->
      <ul role="list">
        {#each items as item}
          <li class="[&.is-dragging]:active:cursor-grabbing">{item}</li>
        {/each}
      </ul>
    `}
  />
  <CodeBlock
    example={css`
      .\[\&\.is-dragging\]\:active\:cursor-grabbing {
        &.is-dragging {
          &:active {
            cursor: grabbing;
          }
        }
      }
    `}
  />
</CodeExampleGroup>

若选择器中需要空格，可用下划线代替。例如该任意变体会选中添加了该类名的元素内的所有 `p`：

<CodeExampleGroup
  filenames={["HTML", "Generated CSS"]}
>
  <CodeBlock
    example={html`
      <!-- [!code classes:[&_p]:mt-4] -->
      <div class="[&_p]:mt-4">
        <p>Lorem ipsum...</p>
        <ul>
          <li>
            <p>Lorem ipsum...</p>
          </li>
          <!-- ... -->
        </ul>
      </div>
    `}
  />
  <CodeBlock
    example={css`
      .\[\&_p\]\:mt-4 {
        & p {
          margin-top: calc(var(--spacing) * 4);
        }
      }
    `}
  />
</CodeExampleGroup>

也可以在任意变体中使用 `@media`、`@supports` 等 at-rule：

<CodeExampleGroup
  filenames={["HTML", "Generated CSS"]}
>
  <CodeBlock
    example={html`
      <!-- [!code classes:[@supports(display:grid)]:grid] -->
      <div class="flex [@supports(display:grid)]:grid">
        <!-- ... -->
      </div>
    `}
  />
  <CodeBlock
    example={css`
      .\[\@supports\(display\:grid\)\]\:grid {
        @supports (display:grid) {
          display: grid;
        }
      }
    `}
  />
</CodeExampleGroup>

在 at-rule 形式的任意变体中不必写 `&` 占位符，与预处理器里嵌套写法类似。

### 注册自定义变体

若同一个任意变体在项目中反复出现，不妨用 `@custom-variant` 抽成正式变体：

```css
@custom-variant theme-midnight (&:where([data-theme="midnight"] *));
```

然后在 HTML 中使用 `theme-midnight:<utility>`：

```html
<!-- [!code classes:theme-midnight:bg-black] -->
<html data-theme="midnight">
  <button class="theme-midnight:bg-black ..."></button>
</html>
```

更多说明见[添加自定义变体](/docs/adding-custom-styles#adding-custom-variants)文档。

### 伪类参考

以下是 Tailwind 中全部伪类变体的示例汇总，可与本指南开头的[伪类文档](/docs/hover-focus-and-other-states#pseudo-classes)对照阅读。

#### :hover

使用 `hover` 变体，在鼠标悬停时应用样式：

```html
<!-- [!code classes:hover:bg-white] -->
<div class="bg-black hover:bg-white ...">
  <!-- ... -->
</div>
```

#### :focus

使用 `focus` 变体，在元素获得焦点时应用样式：

```html
<!-- [!code classes:focus:border-blue-400] -->
<input class="border-gray-300 focus:border-blue-400 ..." />
```

#### :focus-within

使用 `focus-within` 变体，在元素自身或其子元素有焦点时应用样式：

```html
<!-- [!code classes:focus-within:shadow-lg] -->
<div class="focus-within:shadow-lg ...">
  <input type="text" />
</div>
```

#### :focus-visible

使用 `focus-visible` 变体，在通过键盘获得焦点时应用样式：

```html
<!-- [!code classes:focus-visible:outline-2] -->
<button class="focus-visible:outline-2 ...">Submit</button>
```

#### :active

使用 `active` 变体，在按下（激活）元素时应用样式：

```html
<!-- [!code classes:active:bg-blue-600] -->
<button class="bg-blue-500 active:bg-blue-600 ...">Submit</button>
```

#### :visited

使用 `visited` 变体，在链接已访问过时应用样式：

```html
<!-- [!code classes:visited:text-purple-600] -->
<a href="https://seinfeldquotes.com" class="text-blue-600 visited:text-purple-600 ..."> Inspiration </a>
```

#### :target

使用 `target` 变体，当元素 ID 与当前 URL 片段匹配时应用样式：

```html
<!-- [!code classes:target:shadow-lg] -->
<div id="about" class="target:shadow-lg ...">
  <!-- ... -->
</div>
```

#### :first-child

使用 `first` 变体，当元素是第一个子元素时应用样式：

```svelte
<!-- [!code classes:first:pt-0] -->

    <li class="py-4 first:pt-0 ...">
      <!-- ... -->
    </li>
  {/each}
</ul>
```

#### :last-child

使用 `last` 变体，当元素是最后一个子元素时应用样式：

```svelte
<!-- [!code classes:last:pb-0] -->

  {#each people as person}
    <li class="py-4 last:pb-0 ...">
      <!-- ... -->
    </li>
```

#### :only-child

使用 `only` 变体，当元素是唯一子元素时应用样式：

```svelte
<!-- [!code classes:only:py-0] -->

      <!-- ... -->
    </li>
```
