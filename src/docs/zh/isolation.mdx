### 基本用法

使用 `isolate` 和 `isolation-auto` 工具类，控制元素是否显式创建一个新的层叠上下文：

```html
<!-- [!code classes:isolate] -->
<div class="isolate ...">
  <!-- ... -->
</div>
```
