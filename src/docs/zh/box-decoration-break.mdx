## 示例

### 基本用法

使用 `box-decoration-slice` 和 `box-decoration-clone` 工具类，控制 background、border、border-image、box-shadow、clip-path、margin、padding 等属性在元素跨行时是当作一个整体片段渲染，还是按每段独立渲染：
